# 需求与验收

## 用户与目标

帮助内容团队审核待处理素材，检查已有排期，并形成可确认的排期草稿。输入包括请求 ID、素材 ID、渠道、发布时间和时长；本项目使用合成的素材、规则和已有排期数据。

每项素材输出审核状态、风险原因、原定时间、建议时间、确认状态和草稿保存状态。真实发布不在本项目范围内。

## 验收要求

1. 审核通过且时间可用：按请求生成草稿。
2. 素材不存在或必填信息缺失：给出缺失原因，不保存草稿。
3. 命中规则或没有版权授权：标记风险并阻止保存。
4. 同渠道时间区间重叠：查询候选时段；改变原定时间需要用户明确确认。
5. 同一请求重复提交：返回同一份草稿；相同请求 ID 携带不同内容应报冲突。
6. 保存失败、模型失败或达到轮数上限：明确返回未完成，不能报告虚假的保存成功。

真实模型运行需展示模型在不同工具结果下选择不同后续动作。离线 Mock 仅验证业务流程。
